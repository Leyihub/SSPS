# 外部评审第三轮结论与验收用例（2026-11-05）

## 1. 第三轮核对结论

1. 第二轮被指出的 13 条全部撤回，并给出了原文出处。它另外自查撤回了 7 条（镜像表编号、远期路径口径、自然语言能力、T02 没有「允许靠泊船型」、T10 字段、成品船日期语义、错误值行数）。撤回理由与材料一致。
2. 用真实库存表复核：错误值按「库存」列是 248 行；另有 4 行「库存」为 0、「可用天数」为错误值，合计 252 行，两边口径都对。可用天数偏差超过 1.5 天的 112 行，复算一致。
3. 新增且已核实的两点：
   - 靠船计划的「船舶类型」写的是「销售成品船」（数据摘要第 304 行），T04 是「成品销售船」。导入时要归一，已写进 T10 导入规则。
   - 降级到稀疏候选选备选方案时，原型不检查 30%。这是对锁定规则 5 的理解问题，已列入待确认事项。
4. 无法复算的统计（大宗 / 成品 / 物资航程样本数、靠船计划 98 行和池内 84 行、大宗归并 22 组、MMSI 冲突、品名字面匹配 17/37）：需要靠船计划和船舶动态表两份原件。这些数字与第一、二轮一致，且池内 / 池外重算正确，作为参考值使用，写代码时迁移脚本会重新输出。
