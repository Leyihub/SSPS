## 4. 我这边的开发顺序（阶段 A，按依赖排）

1. 工程底座：`server/`（Node 22、ESM、零依赖、`node:test`）、日期工具、统一配置（所有暂定值集中在一处）。
2. `domain/`：状态推导、时序校验、航程规则（P50/P80、样本 ≥5 切统计值）。
3. `engine/`：容量（CMR、重叠船数）、库存断料、推荐（Plan A/B、低可信、最快到港）、宣船文案、S1 溯源。
4. `nlp/`：自然语言解析（船型、物料、货量、航线、截止日）。
5. `importers/`：靠船计划（90 天过滤、泊位归一）、库存表（错误值行）、迁移清洗规则（港口归一、船名拆分、归并、去重、数值化）。
6. `lark/`：token 缓存、多维表格分页读和 500 条批量写、单线程写队列、幂等键与补偿；全部可注入假 `fetch` 测试。
7. `db/schema.sql`：D01–D12 建表，带审计列和 RLS。
8. 与原型引擎的对照测试：同一份示例数据，预测、日历、断料结果逐项一致。
