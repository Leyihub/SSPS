## 权限分组（2026-11-04 确认；2026-11-16 把费用结算拆成两组）

T06 的字段按权限分成三组，分别鉴权。组号与完整授权表见 `field-groups.md`。

1. **卸船作业（G07）**：卸货条款、卸率、允许卸货天数、TURN TIME、卸港水尺吨位、水尺 1–3、汽运量、管带机运量、过磅重量、其他部门运量、倒运车数、X1 管带机车数、跨月船汽运 / 管带机预估、3# / 4# 管带机未运行小时、交接发出日 / 签回日、德天不用交接、小雨保函、影响卸船因素 / 异常反馈。全员可看；大宗采购部（本人航次或本部门主管）和仓储物流部可登记和修改。
2. **港口费用（G08）**：汇率、港务费单价、港务费（USD）、装卸费（USD）。由仓储物流部登记和修改；仓储物流部、大宗采购部和系统管理员可看，其他岗位接口不返回。
3. **合同结算（G09）**：滞期费率 + 币种、滞期费 / 速遣费（USD）。只有大宗采购部（本人航次或本部门主管）和系统管理员能看和改，其他岗位接口不返回。

2026-11-16 的变化：原「费用结算」一组只有大宗采购部能看能改；按责任清单，港务费和装卸费实际由仓储船务填，所以拆出港口费用一组交给仓储物流部，大宗采购部对这一组改为只读。

船抵卸港后才能登记这三组；每次修改记入 D02 变更日志，金额变更只记「已修改」。历史只读航次不可改。

每班的卸船量不在本表，记在应用库 D15 作业日志里（一行 = 日期 + 班次 + 合同 + 车次 + 吨数），累计量由系统汇总。
