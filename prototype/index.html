SSPS 智慧发船预测系统 · 产品原型

这是 P01–P10 共 10 个页面的可点击原型，用来让 Leyinet 评审页面与规则，评审确认之后才进入妙搭开发。原型只用原生 HTML / CSS / JS，示例数据全部虚构，不连飞书，也不是任何已上线功能。

系统的核心是「智能发船计划预测」：帮业务员根据泊位承载能力、航行周期和到港规律，判断最佳发船日、最佳到港窗口和泊位是否够用。它不是港口实时调度塔台，也不做数字孪生大屏。
